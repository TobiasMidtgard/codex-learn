Every time a function is created in JavaScript, it quietly keeps a reference to the scope around it. That pairing — the function plus its birth environment — is a closure. The outer function can finish and return; the variables it held stay alive as long as something still points at them.

Annotated example
function greeter(name) {
return () => `hi ${name}`; // ← captures name
}
